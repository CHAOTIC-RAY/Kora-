Kora

Kora is a personal reading and news app. It runs in the browser as an installable progressive web app and packages for Android, with a Cloudflare Worker handling the network layer. What you can read, browse and send comes from plugins — sources, integrations, tools and themes — so the app you install is the one you configure.

  • React 19 + Vite
  • Android APK
  • Cloudflare Worker
  • Firebase Auth + Firestore
  • MIT licensed

Documentation

  • Features

    What Kora does, organised by what you can do with it: reading, the library, Discover, sending to an e-reader, the Workshop tools, themes and the Android build.

  • Run it yourself

    Deploy your own instance: what you need, the exact Wrangler commands, environment variables, deploying the Firestore rules, building the APK, and troubleshooting.

  • Architecture

    How the backend fits together: Worker request routing, the image and file proxies, the SSRF guard, the R2 relay, Firebase, the plugin runtimes, the search engine ladder and proxy-by-default images.

  • Build a plugin

    Author a source, integration, tool or theme. The source definition format, the two runtimes and how to choose, the readability gate, and hosting your own registry.

    • Quick start

    1. Install the Android build from Releases, or open the web app at kora.chaoticstudio.workers.dev.
    2. Open Discover to reach the plugin hub, then install a source to get content.
    3. Open a book to read it, then use Send to device to move it to an e-reader.

    Full detail for each step is in Features.
