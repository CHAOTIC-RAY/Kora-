Features

What Kora does

Kora is a reading and news app with a plugin system at its centre. You install sources to get content, integrations to reach things you already own, tools for small jobs, and themes to change how it looks. This page covers what you can do once it is installed, and where each thing lives.

#Reading

Book reader

Open a book from Library

EBooks open in a paginated reader with adjustable text size, line spacing and margins. Reading position is saved per book and restored when you reopen it.

Not included DRM-protected books cannot be opened. Kindle purchases are not supported.

PDF reader

Open a PDF from Library

PDFs open in a dedicated reader rather than the book reader, and support page navigation, zoom and text search.

News feed reader

Read tab

A scrolling feed of articles with a full-screen reader. Each entry shows its publication time next to the new/read badge. Feeds are managed from the same surface via Manage Feeds & Sources.

Note The Read tab can be turned off in Settings.

#Comic reader

Swipe, tap and zoom

Open a series or chapter

Swipe to turn pages in reading order, tap the screen edges to show controls, double-tap to zoom on the point you tapped, pinch to zoom and drag to pan while zoomed. Pages ahead of the current one are prefetched so a turn does not wait on the network, and you can step to the next or previous chapter without leaving the reader.

Not included There is no page-thumbnail scrubber; navigation is by swipe, tap zones or chapter stepping.

Reading direction

Series settings

Manga defaults to right-to-left. A right-to-left book opens on its last page and pages forward towards the start of the volume, which is the opposite of what a left-to-right book does. Set it per series if the default is wrong for a title.

#Supported formats

Kora identifies a file by its contents, not its extension. A download named .epub that is actually an HTML login page is rejected and reported as a bad mirror rather than sent to the reader.

Comic archive (ZIP).cbz, .zipComic reader
Comic archive (RAR).cbrNot yet
Comic archive (7z).cb7Not yet

Single image.jpg, .png, .webp, .gif, .avif, .bmpComic reader, one page

Not supported yet

RAR and 7z comic archives (.cbr, .cb7) are detected with certainty and cannot be opened yet. A CBR is a RAR, so identifying it is not the problem — decompression is, and that needs a decoder Kora does not currently ship. The app says so rather than opening a blank page.

MOBI and AZW3 are detected but have no reader. AZW3 is reported as MOBI because the two cannot be told apart from the file's header alone.

Password-protected and split archives are refused up front rather than half-opened, because a split archive extracts to nothing usable when only the first volume arrives.

#Library

Series grouping

Library

Multi-volume series collapse into a single tile by default, so a 30-volume set is one row rather than thirty. Open the group to pick a volume. Turn grouping off to see every book individually.

Metadata and covers

Book detail

Edit title, author and series, and replace the cover with your own image.

Device sync

Settings › Devices

Signed-in devices can be listed and signed out from the same panel.

Not working yet Loading the library is currently blocked by a Firestore permissions gap: the deployed rules allow reading a single document but not querying a collection, so a library query is denied. See deploying the Firestore rules.

#Discover

Source chips

Discover

Each installed source appears as a chip. Tap one to browse its catalogue: popular titles, latest updates, and search.

Plugin hub

Discover

One screen lists everything the registry offers — sources, tools, integrations and themes — with install and remove on each entry. This is the only screen where plugins are managed.

Not included There is no second plugin list anywhere else in the app. Installed plugins appear on their own surface once installed, not in a second management list.

Restricted sources

Discover

A source marked piracy or nsfw is hidden until you switch it on for that source specifically. The card is amber and labelled Shadow library or Adult. The choice is remembered on the device.

Scope Only sources are gated. Themes, integrations and tools are never hidden behind this switch.

#Plugins

Four categories, and an installed plugin of each category shows up in a different place:

Plugin categories and where they appear
CategoryWhat it isAppears in

IntegrationA bridge to something you already own, such as a Calibre serverWorkshop

ThemeA colour schemeSettings

To add a source: open Discover, install it from the hub, then tap its chip. Installing a restricted source also grants its per-source permission.

Writing your own is covered in Build a plugin.

#Send to a device

Kora relay

Book › send

Move a file to a Kobo, Kindle or another phone without a third-party service. The sending device shows a 4-character code, the receiving device types it in, and the file transfers directly. The file is deleted as soon as it is pulled.

Limits 50 MB per file. Codes expire after 6 hours; files after 1 hour. Five wrong code entries expire the code.

Send to Kobo / Kindle

Book › send

Amazon's official Send to Kindle page opens in a new tab; drag the file onto their drop zone. Kobo transfers go through the Kora relay above.

croc

Workshop › croc

Run croc send book.epub on your computer and type the code it prints into the Kora panel to receive the file.

Not included Receiving only. Kora cannot act as the sending peer, because the browser build of croc is not published.

Game Score Tracker setup

Workshop › Game Score Tracker

The wizard walks six steps:

  1. Game Preset — pick the ruleset
  2. Verify Rules — win condition and target score
  3. Turn Timer — clock and competition mode
  4. Roster — names and handicaps
  5. Competition Roster — verify the seeded field
  6. Start Game — review and launch

Note With competition mode off, step 5 is marked skipped rather than removed, so the numbering stays the same either way. Swapping the preset asks first, because it discards manual edits to steps 2–5.

#Themes

Installed themes

Settings

Install a theme from the hub, then choose the active one in Settings. A theme changes colours, contrast and surface styling across the app including the readers.

#Download control

Queue control

Settings › Download Control

Shows active and finished downloads. Cancel, retry and dismiss items individually, and set how many download at once with the concurrency slider. A retry re-downloads and re-checks the file rather than resuming a broken one.

#Android

Signed APK

Releases

Every push to main or beta that changes app code builds a signed APK and publishes it as a release tagged apk-v1.0.<build number>. Download the latest from Releases.

Install Allow installs from your browser or file manager when Android prompts. The APK is not on the Play Store.
